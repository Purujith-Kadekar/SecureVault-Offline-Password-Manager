# Flasher Firmware Binaries

Place your compiled ESP32-S3 firmware binaries here. These files are referenced by `../manifest.json`.

## Required files

| File | Flash offset | Source |
|------|-------------|--------|
| `bootloader.bin` | `0x0` | ESP-IDF bootloader (auto-generated by PlatformIO) |
| `partitions.bin` | `0x8000` | Partition table from `partitions.csv` |
| `boot_app0.bin` | `0xe000` | Boot app stub (from ESP-IDF) |
| `firmware.bin` | `0x10000` | Main application firmware |

## How to extract binaries from PlatformIO build

After a successful `pio run -t upload`, the binaries are in:

```bash
# Find the build output directory
find .pio/build -name "*.bin" -type f
```

Copy these files:

```bash
# From the firmware directory after building:
cp .pio/build/esp32-s3-pro/firmware.bin flasher/firmware/firmware.bin

# The bootloader, partitions, and boot_app0 are also in the build dir:
cp .pio/build/esp32-s3-pro/bootloader.bin flasher/firmware/bootloader.bin
cp .pio/build/esp32-s3-pro/partitions.bin flasher/firmware/partitions.bin

# boot_app0.bin comes from the ESP-IDF framework:
find .pio/packages -name "boot_app0.bin" -exec cp {} flasher/firmware/ \;
```

## Important notes

- **These binaries must be for ESP32-S3 chip family only.** The manifest specifies `ESP32-S3` — flashing an ESP32 or ESP32-C3 binary will not work.
- **Always rebuild after code changes** — do not ship stale binaries.
- **Test the flasher locally** by serving the `flasher/` directory with any static file server:
  ```bash
  cd flasher
  python -m http.server 8080
  # Open http://localhost:8080 in Chrome
  ```
- The `manifest.json` offsets are standard for the ESP32-S3 flash layout. If you change the partition table, update the offsets accordingly.
